# DMIT 註冊教學：從填資料、Email 驗證到付款開通，新手帳號與 VPS 一次買對

DMIT 的註冊流程本身不難，真正會讓人卡住的是幾個細節：姓名不能用中文、服務條款要手動拉到底才能關掉、Email 驗證碼要另外輸入，最後結帳還會遇到付款方式的匯率問題。很多人就是在這幾步放棄，或是在不清楚方案差異的情況下先付了年費。

這篇按照實際操作順序走一遍，從建立帳號到拿到伺服器登入資訊，順便把各機房、各線路的方案價格整理成一張表，讓你在同一個頁面上決定要買什麼。

## 註冊前先準備這四樣東西

- **一個能收信的 Email**：Gmail 或任何常用信箱都可以，註冊後會收到驗證碼，之後的開通信也在同一個位置。
- **一種付款工具**：DMIT 目前接受 PayPal、信用卡和支付寶，選一個你已經打通的就夠。
- **姓名拼音**：註冊欄位只吃英文字母，中文姓名請轉成拼音，例如「王小明」填成 Wang / Xiaoming。這一步很多人第一次都會填錯。
- **手機號碼**：部分下單流程會要求填手機號並接收簡訊驗證碼，建議先確認號碼可以正常收訊。

官網右上角可以切換介面語言，英文版看不太順的話先切成中文再開始。

## 第一步：建立 DMIT 帳號

進入官網後點右上角的註冊入口，填寫姓氏、名字、Email 和密碼。三個容易出錯的地方：

1. **姓名一律用拼音**，出現中文字元會直接卡住送出。
2. **人機驗證**要先勾選，通過後才能繼續。
3. **服務條款要展開後滾動到底**，等倒數計時結束，「Close」按鈕才會變成可點擊。直接關掉視窗是不行的。

以上都完成後點「Create Your Account」提交。

## 第二步：完成 Email 驗證

帳號送出後不會直接進到後台，系統會先要求驗證信箱。頁面上會有一個「send code」按鈕，點下去之後到信箱收驗證碼，複製貼回對應欄位，再點「Confirm」。

收不到信的話先檢查垃圾郵件或促銷分類，這類系統信的投遞位置常常不在主要收件匣。驗證碼有時效，過期就重新點一次 send code。

驗證通過後會跳轉到客戶中心。新帳號還沒有任何服務，頁面會顯示「No Products/Services Ordered, Order Now」之類的提示，點進去就是方案選購頁。

## 第三步：挑機房、線路和方案

DMIT 有洛杉磯、香港、東京三個機房，每個機房底下又分不同線路系列。這部分的差異比價格更值得先搞清楚：

- **Premium（Pro）**：中國電信 CN2 GIA 三網優化線路，國內連線品質最好，價格也最高。
- **Eyeball（EB）**：走 CMIN2 與 9929 這類線路，回程優化，價格介於中間，家用寬頻場景夠用。
- **Tier 1（T1）**：純國際線路，不含中國方向優化，但價格便宜、流量給得多。
- **Premium Secure**：帶高防的 CN2 GIA 線路，有 DDoS 防護需求的才會用到。

Tier 1 系列的高速流量用完之後是降速不停機，例如洛杉磯 T1 會降到 100Mbps～1Gbps 繼續不限流量使用，香港與東京 T1 則多半降到 50Mbps。這對不在意尖峰速度的人來說，等於買了半個不限流量方案。

選定方案後點「Order Now」或「Continue」進入配置頁。缺貨的機型會標示 Out of Stock，只能換別的方案或等補貨。

## 第四步：設定計費週期、系統與登入方式

配置頁要處理的東西比想像中多，逐項看一下：

**計費週期**：月付、季付、半年付、年付都有，週期越長單價越低，實際折扣在購物車裡會即時顯示。新用戶建議先月付或季付測試，理由在後面的退款段落會說明。

**作業系統**：常見 Linux 發行版都在選單裡。之後打算裝寶塔或 1Panel 這類面板的話，選 Debian 或 Ubuntu 比較省事。

**root 密碼與 SSH 金鑰**：建立實例時要設定 root 密碼，同時系統會產生一組 SSH 金鑰。首次進入實例頁面會跳出下載提示，私鑰只能下載一次，之後看到的是「重新生成金鑰」。**這一步沒下載，就只能重新生成一把新的**，記得先存好。

**加購項目**：額外的 IPv4、記憶體、系統碟都可以加，但每一項都是另外計費，預設配置對大多數人已經夠用，不需要為了「以後可能用到」先加。

## 第五步：購物車與優惠碼

點「Continue」之後進到訂單總覽，確認方案、週期和金額沒有看錯。

購物車頁面會有「Apply Promo Code」欄位，輸入後點「Validate Code」驗證。要提醒的是，DMIT 長期公開的通用優惠碼並不多，網路上流傳的折扣碼很多都已經失效，驗證不過就是沒用了，不要預先把折扣算進預算裡。真正穩定會反映在價格上的，是拉長計費週期帶來的折扣。

## 第六步：填寫個人資料並付款

第一次下單的人在這一步才需要補齊帳號資料：姓名、Email（同時作為登入帳號）、手機號、國家／地區、密碼。前面註冊時填過的部分通常會自動帶入。

提交後如果跳出簡訊驗證頁，輸入手機收到的驗證碼再點 Submit 就好。號碼填錯可以回頭修改重填。

付款方式三選一：

- **支付寶**：會依當時匯率自動換算人民幣，掃碼或登入付款都可以。
- **PayPal**：如果系統預設用人民幣結算，建議手動切回美元，PayPal 的匯率通常比銀行差。
- **信用卡**：Visa、MasterCard 等主流卡別。

選好付款方式、勾選同意條款，點「Complete Order」完成付款。

## 第七步：開通後取得連線資訊

付款完成後系統會自動開通，通常幾分鐘到十幾分鐘內完成，伺服器 IP、登入帳號等資訊會寄到註冊信箱。

登入客戶中心左側的服務清單可以看到已訂購的實例。第一次點進去會提示下載金鑰，解壓後會拿到 `id_rsa.pem`（還有 `.ppk` 格式給 PuTTY 用）。用 Xshell、Termius 這類工具連線時，使用者名稱填 `root`，再選剛剛下載的 `.pem` 私鑰。

遇到問題可以在後台開工單，中文溝通沒有障礙。

## 新手最該注意的一件事：退款政策

這也是我建議第一次先買月付的原因。

根據官方文件，DMIT 提供**新訂單 3 天內全額退款**，條件是購買不超過 3 天、且傳輸量不超過 30GB；超過 3 天但在 30 天內，則可按剩餘價值部分退款，計算方式是取「已用流量比例」與「已用時間比例」中較高的一項來扣。退款通常 48 小時內處理。

幾個實務細節：

- 退款可以退回 DMIT 帳戶餘額（不收手續費），或退回原支付方式（扣除支付網關手續費，支付寶因退款會返還手續費而不收）。
- 提出退款申請後實例會被關閉，避免繼續消耗流量。想自己先關機也可以，能減少退款期間的流量爭議。
- 帳戶餘額支付的訂單、續訂訂單不在退到原付款方式的範圍內。
- 被拒絕的常見原因包括：同系列產品已退款 3 次、以「網路不夠好」或 IP 地理位置為由、遭受 DDoS、以及已使用超過 3GB 流量後才反映 IP 在某些地區不可用。

所以流程是：付款後當天先測路由與速度，有問題立刻開工單找銷售部門，不要拖過三天。

## 常見問題

**為什麼註冊完看不到某些方案？**
方案是分開的產品，有些要看庫存狀態。客戶中心裡的訂購入口會列出目前的在售選項，標示 Out of Stock 的就是暫時買不到。

**姓名可以填中文嗎？**
不行，要用拼音，而且資料之間要保持邏輯一致，例如選了美國，州別、城市、郵遞區號要對得上。

**註冊到底要不要實名？**
註冊時填的是姓名、Email、手機號這類基本資料，沒有要求上傳身分證件或營業執照。手機號建議填能正常收訊的號碼，簡訊驗證會用到。

**付款後多久可以開始用？**
大多在幾分鐘到十幾分鐘內完成開通，實際時間取決於付款方式與驗證狀態。開通資訊會寄到註冊信箱。

**優惠碼去哪裡找？**
結帳頁的「Apply Promo Code」欄位可以驗證手上的碼。DMIT 沒有長期固定的大額公開碼，拉長計費週期帶來的折扣反而比較實在。

**買哪個線路比較划算？**
只看價格，洛杉磯 Tier 1 年付 $36.90 起是門檻最低的；要顧中國大陸連線品質，洛杉磯 Premium 的 $9.99/月起（含 AN4 世代機型）是常見折衷；香港則直接貴一檔。先想清楚你是要「便宜大流量」還是「低延遲」，再決定機房。
